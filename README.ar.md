# EditDNA 🧬
**حوّل قناتك لستايل مونتاج خاص بيها.. وبعدها اعمل مونتاج أي فيديو بالستايل ده بجملة واحدة.**

EditDNA سكيل للإيجنتس (Claude، وClaude Code، وOpenCode). بتسألك عن قناتك، وبتشوف سكرينات من ستايلات مونتاج انت بتحبها،
وبتصمملك ستايلك انت (ألوان، خطوط، أشكال، حركة، مؤثرات صوت، لوجو، وشخصية لو عندك)، وتوريك تجربة، وبعدها تبنيلك سكيل تانية
باسم قناتك بتعمل مونتاج فيديوهاتك بالستايل ده من الفويس أوفر.

## محتاج إيه
- Python 3.10 أو أحدث، و ffmpeg
- إيجنت بيقدر يشغّل أوامر: تطبيق Claude (مدفوع) · Claude Code · OpenCode (فيه موديلات مجانية)

## البداية
1. نزّل الريبو ده (Code ← Download ZIP) وفك الضغط.
2. ادّي الإيجنت فولدر `editdna-builder` كسكيل وقوله:
   **«استخدم سكيل editdna-builder وابنيلي ستايل المونتاج بتاع قناتي»**
3. جاوب على أسئلته، وابعتله السكرينات واللوجو، ووافق على التجربة.
4. وبعد كده: **«استخدم سكيل ‹اسم-قناتك›-editdna واعمل مونتاج الفيديو ده: الفويس vo.wav والسكرينات في فولدر shots»**
