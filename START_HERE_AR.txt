EditDNA — ابدأ من هنا (شرح خطوة بخطوة)
==========================================
الأداة دي بتعمل حاجتين:
  (1) تسألك عن قناتك وتشوف سكرينات من ستايلات انت بتحبها، وتصمملك ستايل مونتاج خاص بيك.
  (2) تبنيلك سكيل باسم قناتك، تعمل بيها مونتاج أي فيديو بالستايل ده بجملة واحدة.

■ الحاجات اللي محتاجها مرة واحدة بس
1) Python: من python.org/downloads نزّل آخر نسخة، ووقت التسطيب علّم على "Add Python to PATH".
2) FFmpeg: افتح Command Prompt واكتب:   winget install Gyan.FFmpeg
   (على الماك: brew install ffmpeg)
3) إيجنت يشغّل الأداة — اختار واحد:
   • ببلاش: OpenCode (من opencode.ai) وفيه موديلات مجانية.
   • مدفوع: تطبيق Claude (اشتراك Pro) أو Claude Code.

■ تسطيب السكيل
• تطبيق Claude: Settings ← Capabilities ← Skills ← Upload skill ← اختار ملف editdna-builder.zip
• OpenCode أو Claude Code: انسخ فولدر editdna-builder جوه فولدر السكيلز
  (OpenCode: ‎~/.config/opencode/skills   |   Claude Code: ‎~/.claude/skills)

■ بناء الستايل بتاعك
1) اعمل فولدر جديد (مثلاً D:\MyChannel) وحط فيه:
   - لوجو قناتك (PNG من غير خلفية لو تقدر)
   - فولدر اسمه refs فيه من 2 لـ 6 سكرينات من فيديوهات مونتاجها عاجبك
   - (اختياري) صورة شخصية/ماسكوت للقناة
2) افتح الإيجنت على الفولدر ده واكتبله:
   استخدم سكيل editdna-builder وابنيلي ستايل المونتاج بتاع قناتي
3) جاوب على أسئلته (بيسألك سؤال أو اتنين في المرة).
4) هيوريك صورة فيها كل العناصر + فيديو تجربة 6 ثواني. قوله تعدّل إيه بكلامك العادي
   («ألوان أهدى»، «الخط أتخن»، «حركة أقل») لحد ما يعجبك.
5) لما توافق، هيعملك فولدر سكيل جديد باسم قناتك (‹اسم-القناة›-editdna). سطّبه بنفس طريقة فوق.

■ عمل فيديو (من هنا ورايح)
1) اعمل فولدر للفيديو وحط فيه: vo.wav (الفويس أوفر) + script.txt (النص اللي اتقرا) + فولدر shots فيه السكرينات.
2) اكتب للإيجنت:
   استخدم سكيل ‹اسم-القناة›-editdna واعمل مونتاج الفيديو ده
3) هيطلعلك preview.mp4 الأول (سريع، للمراجعة بس)، وبعدها final.mp4 بجودة 1080p و60 فريم.
   للشورتس قوله: «اعمله شورت 9:16 بكابشنز».

■ مشاكل شائعة
• "python is not recognized" ← سطّب Python تاني وعلّم Add to PATH، وافتح Command Prompt جديد.
• "ffmpeg is not recognized" ← اقفل وافتح Command Prompt بعد تسطيب FFmpeg.
• أول مرة بيفرّغ الصوت بياخد وقت عشان بينزّل موديل التفريغ (مرة واحدة بس).
